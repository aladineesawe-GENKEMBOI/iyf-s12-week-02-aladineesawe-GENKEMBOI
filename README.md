# Week 2: CSS Mastery

## 📌 Project Overview

This repository contains my Week 2 CSS Mastery assignments. The project focuses on transforming a basic HTML portfolio into a modern, attractive, accessible and responsive website using CSS.

## 🎯 Learning Objectives

* Understand CSS fundamentals and the box model.
* Apply typography and colour systems using CSS variables.
* Build layouts using Flexbox and CSS Grid.
* Create responsive websites using media queries.
* Improve user experience with hover effects and transitions.
* Apply accessibility and keyboard focus styles.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Google Fonts
* Visual Studio Code
* Git and GitHub
